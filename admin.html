⚙️ 解析规则（必填，见下方示例说明）
添加后点下方"保存到 GitHub"立即生效
解析规则示例：
① CSS（网页列表）：条目选器填列表项，标题/日期/链接选器填该项内对应元素。打开网站按 F12 检查元素即可复制选择器。

③ JSON 接口：如果网站有数据接口（F12 → 网络 → 找返回 JSON 的请求），填接口地址和字段名。
需要登录的网站：登录后 F12 → 网络 → 复制 Cookie 发给 Agent 写入本地（不会公开）。
