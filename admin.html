  2. 方式 B：点击「生成配置 JSON」复制内容，直接发给 Agent，Agent 验证后写入并立即抓取一次。
    3. 
      
  3. 想立即看效果：保存后告诉 Agent「试抓一次」，Agent 会马上运行抓取并把结果更新到看板。
    4. 
      
  4. 修改或删除：在 GitHub 仓库 kennykaipro/bidding-board 的 sources_config.json 里直接编辑（有注释示例）。

4 常见问题

    

      
不知道 CSS 选择器怎么写？ 把网站网址告诉 Agent，Agent 帮你探测结构、自动生成解析规则并配置好。

      
网站列表是动态加载的（JS渲染）？ 目前脚本版抓不到，后续可用云电脑浏览器方案补抓，或让 Agent 用浏览器方案处理。

      
提交到 GitHub 会泄露 Cookie 吗？ 不会。Cookie 只进本地敏感配置，公开仓库只保存网址和解析规则。

      
为什么需要 Token？ 网页是纯静态托管没有后端，写配置直接调用 GitHub API，Token 仅在你浏览器里使用，我们这边拿不到。
